서비스 열기서비스 소개

개인정보처리방침

시행일 2026년 10월 19일 (이전 시행일 2026년 10월 14일)

데일리컷(이하 "서비스")은 회원가입과 로그인이 없고, 이름·연락처·계정 같은 개인정보를 받지 않습니다. 아래는 서비스를 이용할 때 어떤 정보가 어디에 남는지에 대한 안내입니다.

1. 서버에 전달되거나 기록되는 정보

접속 기록웹서버가 접속 IP 주소, 접속 시각, 요청한 주소, 브라우저 정보를 자동으로 기록합니다. 보안과 장애 대응이 목적이며 14일 뒤 자동으로 삭제됩니다.
익명 이용 통계어느 화면·기능이 얼마나 쓰였는지를 날짜별 횟수로만 집계합니다. 사용자·기기를 구분하는 값, 위치, 검색어는 저장하지 않으며 개인을 식별할 수 없습니다. 화면의 ⓘ 안내에서 언제든 끌 수 있습니다.
위치(선택)위치 권한을 허용하면 내 지역(시·도)을 찾기 위해 좌표를 서버에 한 번 보냅니다. 서버는 좌표를 소수 둘째 자리로 뭉개 시·도만 계산하고, 좌표를 저장하거나 기록하지 않습니다. 허용하지 않으면 서울로 보이며 직접 지역을 고를 수 있습니다.
홈 화면 위젯(안드로이드 앱)위젯은 앱에 저장된 지역과 내 장바구니·대표 품목을 읽어 약 30분마다(앱을 열지 않아도, 인터넷이 연결돼 있을 때) 서버에서 날씨·가격·공고 요약을 받아 옵니다. 지역과 품목은 요청 본문으로 보내며 서버는 이를 저장하거나 기록하지 않습니다(접속 기록에는 위 일반 접속 정보만 남습니다). 위젯은 위치(GPS)를 읽지 않습니다.
내 조건(선택)정부 지원을 좁혀 볼 때 만 나이·성별·소득 구간·해당 특성을 요청 본문으로 보내 결과를 받습니다. 서버는 이 값을 저장하거나 기록하지 않습니다. 생년월일은 서버로 보내지 않고 기기 안에서 만 나이만 계산합니다.

2. 내 기기(브라우저·앱)에만 저장되는 정보

다음은 서비스 서버가 아니라 사용 중인 브라우저 또는 앱의 저장 공간에만 남습니다: 선택한 지역, 내 장바구니, 위젯에 보일 대표 품목, "내 조건" 입력값(생년월일 포함), 마지막에 본 화면 선택, 익명 통계 끄기 설정. 브라우저의 사이트 데이터를 지우거나 앱의 저장 공간을 지우거나 앱을 삭제하면 함께 삭제됩니다. 앱은 기기 자동 백업(클라우드 백업)을 사용하지 않으므로 이 값이 구글 계정 등으로 복사되지 않습니다.

앱이 요청하는 권한

위치(대략적인 위치)선택 사항입니다. "내 위치로 시작" 또는 "현재 위치로 찾기"를 눌렀을 때만 요청하며, 시·도를 찾는 데만 씁니다. 거부해도 지역을 직접 골라 모든 기능을 쓸 수 있습니다. 정확한 위치는 요청하지 않습니다.
인터넷·네트워크 상태날씨·시세·공고 같은 공공데이터를 받고, 연결이 끊겼을 때 위젯 갱신을 다시 시도하는 데 씁니다.
광고 ID(광고 표시 시)구글 광고가 표시될 때 구글이 광고 제공을 위해 씁니다. 아래 "3. 광고"를 참고해 주세요.

3. 광고

웹사이트에서는 광고를 표시하지 않습니다. 안드로이드 앱에서는 구글 애드몹 광고가 표시될 수 있으며 "광고"라고 표시해 콘텐츠와 구분합니다. 광고가 표시되는 경우 구글이 광고 제공과 성과 측정을 위해 광고 식별자, IP 주소, 기기 정보를 수집·이용할 수 있으며, 이는 위 익명 이용 통계와 별개입니다.

  • 구글이 광고에 데이터를 쓰는 방식: 구글 광고 정책 · 구글 개인정보처리방침
  • 안드로이드 폰의 설정 → Google → 광고에서 광고 맞춤설정을 끄거나 광고 ID를 삭제할 수 있습니다.

4. 외부 서비스

  • 앱 실행에 필요한 일부 파일은 구글의 CDN(gstatic.com)에서 불러옵니다. 이때 구글에 접속 정보가 전달될 수 있습니다.
  • 시장 상세 등의 지도 링크(네이버·카카오)와 데이터 출처 링크를 누르면 해당 사이트로 이동하며, 그곳의 방침이 적용됩니다.

5. 제3자 제공·위탁

서비스는 이용자를 식별할 수 있는 개인정보를 별도로 수집하지 않으므로 제3자에게 제공하지 않습니다. 서버는 Oracle Cloud(일본 도쿄 리전)에서 운영되며, 이 서버에 위 접속 기록(IP 주소 등)이 14일간 저장됩니다.

6. 국외 이전·처리

구글 LLC(미국)항목: 광고 식별자, IP 주소, 기기 정보 · 목적: 안드로이드 앱의 광고 제공과 성과 측정 · 시기와 방법: 광고가 표시될 때 구글 광고 SDK를 통해 네트워크로 전송 · 보유 기간: 구글의 정책에 따름 · 거부 방법: 폰의 광고 맞춤설정 끄기 또는 광고 ID 삭제, 앱 사용 중단. 웹사이트에서는 광고를 표시하지 않으므로 해당하지 않습니다.
Oracle(일본)항목: 접속 기록(IP 주소, 접속 시각, 요청 주소, 브라우저 정보) · 목적: 서비스 운영·보안·장애 대응 · 시기와 방법: 이용 시 서버에 자동 저장 · 보유 기간: 14일 후 자동 삭제.

7. 이용자의 권리

서버에는 이용자를 식별할 수 있는 정보가 저장되지 않으므로 열람·삭제를 요청할 개인 정보가 없습니다. 기기에 저장된 정보는 브라우저의 사이트 데이터 삭제나 앱 삭제로 직접 지울 수 있고, 익명 통계는 ⓘ 안내에서 끌 수 있습니다.
